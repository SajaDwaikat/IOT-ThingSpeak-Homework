
# ESP32 to ThingSpeak: Temperature and Humidity Monitoring

## Project Description
This project uses an ESP32 and a DHT22 sensor
to measure temperature and humidity and send
the readings to ThingSpeak.

## Wiring
- DHT22 VCC -> ESP32 3V3
- DHT22 GND -> ESP32 GND
- DHT22 DATA -> ESP32 GPIO 15
